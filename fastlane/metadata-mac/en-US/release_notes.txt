• New: Import Wizard — load one or more CSV or Excel files into a table. Map source columns to table columns and choose how to write them: Append, Append/Update (upsert by a key), or Copy (empty the table first, then load)
• Run several SQL statements at once — a Summary lists every statement with its message and time, and each SELECT gets its own result tab
• Copy grid results to the clipboard as TSV, CSV, JSON, Markdown or INSERT statements; right-click to copy a single cell or row. Markdown is now a file-export option too
• Colour-tag each connection so production, staging and local stand apart in the sidebar
• Export SQL: an optional speed limit keeps a live database responsive during a large dump
• Fixes: exports and copies now leave out generated/virtual columns, so a dump re-imports cleanly; large exports over an SSH tunnel no longer drop midway; "Empty database first" now clears the whole schema — tables, views, routines and triggers
